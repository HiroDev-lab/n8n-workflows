## Português

### Descrição

Gera e publica automaticamente YouTube Shorts com IA (vídeo, áudio ASMR e legenda).

### Trigger

**Agendado (Cron)**

### Integrações utilizadas

- Code (JS/Python)
- Gmail
- Google Sheets
- HTTP Request
- Scheduler
- Telegram
- Wait/Delay

### Como usar

1. Importe o arquivo `workflow.json` no seu N8N (**Workflows → Import from file**).
2. Configure as credenciais necessárias (substituindo os placeholders `YOUR_CREDENTIAL_ID` / `YOUR_CREDENTIAL_NAME`).
3. Ajuste os parâmetros específicos do seu ambiente (URLs, IDs de contas, etc.).
4. Ative o workflow.

### Pré-requisitos

- N8N versão 1.0+
- Credenciais configuradas para: Code (JS/Python), Gmail, Google Sheets, HTTP Request, Scheduler, Telegram, Wait/Delay
