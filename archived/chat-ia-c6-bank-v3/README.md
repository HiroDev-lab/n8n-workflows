## Português

### Descrição

Chatbot com IA para atendimento do C6 Bank. Utiliza LLM com base de conhecimento e roteamento inteligente.

### Trigger

**Webhook (HTTP)**

### Integrações utilizadas

- Code (JS/Python)
- Conditional Logic
- HTTP Request
- Switch/Router
- Wait/Delay
- Webhook

### Como usar

1. Importe o arquivo `workflow.json` no seu N8N (**Workflows → Import from file**).
2. Configure as credenciais necessárias (substituindo os placeholders `YOUR_CREDENTIAL_ID` / `YOUR_CREDENTIAL_NAME`).
3. Ajuste os parâmetros específicos do seu ambiente (URLs, IDs de contas, etc.).
4. Ative o workflow.

### Pré-requisitos

- N8N versão 1.0+
- Credenciais configuradas para: Code (JS/Python), Conditional Logic, HTTP Request, Switch/Router, Wait/Delay, Webhook
