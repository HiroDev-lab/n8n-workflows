## Português

### Descrição

Gerenciamento central de cards do sistema Kommit. Cria, atualiza e move cards no CRM.

### Trigger

**Agendado (Cron)**

### Integrações utilizadas

- Batch Processing
- Conditional Logic
- Data Transform
- Google Sheets
- HTTP Request
- PostgreSQL
- Scheduler
- Supabase
- Switch/Router
- Wait/Delay

### Como usar

1. Importe o arquivo `workflow.json` no seu N8N (**Workflows → Import from file**).
2. Configure as credenciais necessárias (substituindo os placeholders `YOUR_CREDENTIAL_ID` / `YOUR_CREDENTIAL_NAME`).
3. Ajuste os parâmetros específicos do seu ambiente (URLs, IDs de contas, etc.).
4. Ative o workflow.

### Pré-requisitos

- N8N versão 1.0+
- Credenciais configuradas para: Batch Processing, Conditional Logic, Data Transform, Google Sheets, HTTP Request, PostgreSQL, Scheduler, Supabase, Switch/Router, Wait/Delay
