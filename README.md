### Como importar

1. Acesse seu N8N.
2. Vá em **Workflows → Import from file**.
3. Selecione o arquivo `workflow.json` da pasta desejada.
4. Configure as credenciais (os campos com `YOUR_CREDENTIAL_ID` precisam ser substituídos).
